# Financial Health Dashboard

## Project Overview
This project analyzes the financial health of an organization using Power BI.

## Objectives
- Analyze total revenue and expenses.
- Calculate net profit and profit margin.
- Visualize monthly financial performance.
- Support financial planning and budgeting.

## Tools Used
- Microsoft Power BI
- DAX Measures
- Financial Data Visualization

## Key Results
- Total Revenue: 860,000
- Total Expenses: 487,000
- Net Profit: 373,000
- Profit Margin: 43.37%

## Visualizations
- Revenue vs Expenses Column Chart
- Monthly Net Profit Trend Line Chart
- Profit Margin Gauge Chart

## Note
The project uses sample financial data for demonstration purposes.
